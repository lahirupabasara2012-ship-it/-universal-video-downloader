# 🎬 Universal Video Downloader

A simple and user-friendly Universal Video Downloader Web App built with Python and Flask.

## 🚀 About

Universal Video Downloader is a web application project designed to provide a simple interface for downloading online videos.

The project is currently under development.

## ✨ Features

- 🌐 Web-based user interface
- 🎨 Clean and simple design
- 📱 HTML, CSS and JavaScript frontend
- 🐍 Python Flask backend
- ⚡ Lightweight application

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Gunicorn

## 💻 Installation

### 1. Clone the repository

```bash
git clone https://github.com/lahirupabasara2012-ship-it/-universal-video-downloader.git
```

### 2. Open the project folder

```bash
cd -universal-video-downloader
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

```text
http://127.0.0.1:5000
```
